# Project instructions

- Use only Next.js App Router, TypeScript, Tailwind CSS, shadcn/ui-style components, Drizzle, PostgreSQL, pnpm, Vitest, and Testing Library.
- Do not add services, Docker containers, or dependencies outside this fixed stack.
- Keep the app a small MVP: no more than five principal pages and eight business entities.
- Make the smallest reasonable incremental change.
- Update business tests with new or changed business behavior.
- Run `pnpm typecheck`, `pnpm test`, and `pnpm build` after changes.
- Work only inside `/workspace`; never access host paths or start Docker containers.
